# VibeGuard 工程决定

更新时间：2026-09-30。以下区分客户已确认方向和实施中的临时决定。

2026-10-19 工程建议细化：原 Agent 内主动验收优先，Windows `.exe` 负责安装、连接、复杂审查及证据历史；支持的平台用原生插件打包接入项，仍复用同一 Core，不要求每次打开桌面或复制聊天。该建议基于客户便利性目标与本轮公开文档核查，具体支持仍需实测。继续原 D1–D5 主线，本轮实现 D3 确认要求到冻结计划的第一步，不宣称完整外部执行已完成。见[最终体验](20-product-experience.md)及[规划记录](21-external-planning.md)。

2026-10-18 新增决定：最终提供 Windows `.exe` 本地任务验收台，保留原聊天 MCP 入口及共用 Core；用户明确要求继续打通外部项目验收和证据链。Electron + TypeScript 为工程默认桌面方案，尚未安装或打包；Docker 作为既有外部代码隔离路线继续实施。开源复用和 Windows 交付门槛见[增量计划](17-desktop-and-external-project-plan.md)。

| 决定 | 原因 | 状态 |
| --- | --- | --- |
| TypeScript + Node.js 为主语言和运行环境 | 统一 Core、CLI、MCP、浏览器工具和接入层 | 已确认方向 |
| 默认由用户主动发起验收 | 用户明确验收时点；长任务支持阶段与最终验收 | 2026-09-30 用户明确确认 |
| 自动验收作为可开启模式，默认关闭 | 用户启用后由宿主事件与程序规则触发；干活 Agent 只能申请验收 | 2026-09-30 用户明确确认；自动触发尚未实现 |
| MCP 采用官方 server/client SDK 2.2.0，先用 stdio | 当前官方 v2 稳定线；本地进程复用 Core，不必先提供 Web 服务 | 本轮已锁定依赖并完成协议测试 |
| MCP 接登记引用；绑定会话时允许采集器自动登记，模型与执行范围由服务配置决定 | 不让干活 Agent 提交任意路径、会话、目标或通过结论；保留材料快照与复验历史 | 已实现原型，外部项目执行仍未接入 |
| Jev、Laya 只用于后续优化实验 | 是否节省完整链路成本、是否影响漏检仍须实测 | 已确认方向 |
| Core/CLI 使用规范化完整对话作为首个输入 | 不依赖任何宿主先验证“要求到证据”的能力 | 实施决定 |
| Codex 先用官方只读历史接口做采集试点 | 用户要求直接读取本条真实历史；不依靠模型摘要或 UI 复制，也不猜最近修改的聊天 | 已读取 39 条用户与 137 条助手消息；固定会话绑定，不代表任意新聊天自动接入 |
| 首个主动接入宿主按真实环境与能力选择 | 产品定位跨 Agent；需要完整对话、工具调用与结果显示，自动收尾另验 | 实施决定，待真实宿主验证 |
| M1 只运行本项目自编、可控样例 | Docker 已可连接，但外部代码隔离运行器尚未实现 | 当前开发边界 |
| 主模型采用 DeepSeek Flash | 用户指定；Windows 用户环境变量已配置并在 Codex 重启后可读，单个受控样例真实调用成功 | 已确定，待扩大评估 |
| M2 使用 Pi 官方 `@earendil-works/pi-ai` 0.87.1 | 当前官方包已采用 `@earendil-works` 命名；先调用模型，不引入完整 Agent 运行循环 | 实施决定 |
| 禁用暂不需要的 Google/protobuf 传递依赖构建脚本 | pnpm 11 默认要求对构建脚本明确决策；当前优先验证 OpenAI 路径 | 实施决定，启用其他提供商前复核 |
| M3 模型计划只能调用授权 API 描述中的路由 | 模型可能规划额外的本地接口；按方法和路径结构核对后才允许执行 | 已实现的受控 HTTP 范围 |
| API 描述约束成功状态与独立测试数据 | 真实模型曾把 201 写成 200、跨检查复用优惠券；这些错误会误导验收，执行前由代码核对并绑定描述摘要 | 已实现于受控 HTTP 范围 |
| 本地哈希暂不作为防伪证明 | 同权限进程仍可改写证据和清单；待外部项目隔离与只读证据目录完成后重新定义信任边界 | 当前边界 |
| DeepSeek 默认 `deepseek-flash`，Kimi 默认 `kimi-k3` | 用户指定 Flash；固定且可见的默认值避免模型目录更新时暗中切换验收标准，`--model` 用于显式覆盖 | DeepSeek 单样例实测，Kimi 待实测 |
| 其他模型中台接入前先核对接口与账户范围 | 豆包、硅基流动、百炼不是当前 Pi 内置同名 provider；仅写 README 示例会造成“命令可运行”的错觉 | 待实施 |
