## 当前边界

- M1 的验收计划是手写的，只检查优惠券门槛。正确版本的门槛范围可标 `VERIFIED`，但整个任务因“一次使用”未验证仍为 `UNVERIFIABLE`。
- 运行的是本项目自编受控样例。Docker 已可连接，但当前代码尚未使用容器运行待验收交付；不能宣称任意外部 Agent 代码已被安全隔离。
- 当前终端没有 `claude` 命令，不影响通用 Core/CLI。首个自动接入宿主按完整对话与收尾事件能力实测决定。
- 模型与凭据尚未确定；真实需求整理和动态验收规划未实现。
- M2 的固定输出测试只证明数据契约与程序复核能工作；当前没有真实模型调用成功记录，不能宣称要求抽取准确。
